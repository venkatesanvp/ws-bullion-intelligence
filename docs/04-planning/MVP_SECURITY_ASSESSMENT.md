## Remediation and compatibility

- API: pinned Python 3.13 slim refresh, same Debian 13; uv 0.11.29 -> 0.13.7 while retaining the frozen uv command and unchanged lockfile. No package-resolution upgrade. Runtime UID 10001. Patched apt and compiled Rust advisories disappear; two Debian zlib highs remain.
- UI: build remains pinned Node 22/Bookworm; runtime uses the official pinned Node 22/Alpine 3.24 image, with **zlib=1.4-r0** from its supported signed repository. Only built assets and the built-in Node HTTP server run there; no native npm modules are copied across libc variants. Non-root UID1000/read-only/cap-drop retained. Runtime/CSP/chart/forecast smoke verifies compatibility. Version-pinned APK installation fails if that package becomes unavailable; it never silently selects another version. Pin/lock/base provenance remains enabled.
- DB: PostgreSQL **18.6 / Debian 13 / UID999 / PGDATA=/var/lib/postgresql/18/docker** retained. Official rootfs/entrypoint copied into a final filesystem after deleting gosu; explicit original ENV, ENTRYPOINT, CMD, VOLUME, port and SIGINT semantics retained. The final empty-stage assembly adds no alternative OS or unmaintained binary. Starting directly as postgres is supported by the official image; its root-only chown/gosu branch is not used. Synthetic fresh named volume, tmpfs, existing-volume restarts and dump/restore passed. **No active volume attached or migrated.** Future owner deployment still needs a separately authorized window and volume ownership/locale review; no automatic chown of an existing owner volume is permitted.
- First deletion-only DB candidate still reported deleted-layer Go components. Final filesystem assembly removes those bytes from runtime layers and the unfiltered inventory. Both receipts are retained; no ignore filter was used.
- Intermediate Alpine candidate introduced a zlib critical. It was rejected, patched and rescanned. An attempted edge musl revision was unavailable and the build failed safely; no cross-branch package mixing occurred.

Pinned inputs: Python `sha256:09a17cad02668ae61ece136b4fd36ac3849e14f670ebedb637ea3e15580525bc`; uv0.13.7 `sha256:96f40d3904aad8d0bd010539001d36c8e2188b981e1334471a90c4a1d93bb490`; Node22 Bookworm build `sha256:5ec23b7c622b00547753bc6ffd78085dd868a68aeb41c8e0a1418f033e13d96d`; Node22 Alpine runtime `sha256:0e1754758c2df4cfa3e68d59e2e1b7374bb7fd9ea6328eaaacf15cc934af8202`; PostgreSQL18 Trixie `sha256:e3d24f6906d0760bf4da0dae872415391ededefad23fd471c47dc53b0ddf3c42`.
